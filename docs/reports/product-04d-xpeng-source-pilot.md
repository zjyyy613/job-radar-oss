## 5. 分页 / 去重 / 准入 / 失败处理回归

- **分页**：`start_page`/`page_size`/`max_pages` 对小鹏同样生效（本轮为第 1 页，25 条）；`query_exhausted`、`repeated_page`、`max_jobs`、`global_max_jobs` 逻辑共用且已有回归覆盖。

- **准入**：25/25 通过官方域名 + 含 id + 地点非占位 + 正文 ≥80 字符四类硬条件。
- **失败处理**：与既有流程一致（checkpoint + summary 归档；PARTIAL 退出码 0 需读 summary；按写入前 ID 差集核对/回退，禁止按 `fetched_at` 删除）。
- **测试**：**554 项通过**（550 + 4）、lint 0 warning、typecheck 通过。

## 6. 结论与建议

**① 1.2.1 能否访问小鹏国内实习来源？** 能。域名、分页、id、链接、招聘类型全部核实通过，无需升级。

**② 真正符合产品定位的实习岗位有多少？** 上游 intern 共 **82** 条；第 1 页 25 条 **100% 准入**、**100% 为实习**。其中约 **16/25** 能落入现有类目（技术研发/产品/人力/市场/运营），**9/25** 是零售/交付/售后/大区管培 → 目前无对应类目。

**③ 工程制造类净增潜力？** **intern 渠道为 0**；**campus 渠道为 12/25（48%）**，且正是涂装/总装/焊装/压铸/冲压/三电/工艺规划/制造仿真等目标方向。**因此「补充汽车/机械/工艺方向」的目标无法只靠 intern 达成**——需要为正式校招扩展 scope 能力（本轮按授权边界未做）。

**④ 最小接入涉及哪些文件？** 见第 3 节：2 个 ingest 脚本 + 2 个 fixture + 3 个测试文件（另 `run-job-pro.test.ts` 一处断言）。

**⑤ 是否具备提交生产发布审查的条件？** **具备**（来源契约已证、准入 100%、测试与门禁全绿、默认调度未变、`adapter_version` 已升为 adapter-3 以留审计痕迹）。但必须在发布说明中写明 **intern-only 的岗位价值局限**，避免把「新增来源」误读为「补齐工程制造方向」。

**⑥ 正式写入的合理批量与模型预算**：
- 建议首批 **25 条**（第 1 页）：本地 77.9s，detail 2.85s/条；runner 约 2–3× → **约 150–240s**，在 5 分钟/来源预算内；**50 条会接近或超出**（≈8.5s/条 × 50 ≈ 425s），故 **XPeng 单次不超过 25 条**。
- 模型调用：按 0.15 次/条 × 25 ≈ **4 次**，建议 `model_cap=10`。
- 建议参数：`sources=xpeng, scope=intern, start_page=1, page_size=25, max_pages=1, max_jobs=25, global_cap=25, model_cap=10`。
